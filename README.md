# VoluMin

Aplikasi Android untuk meredam volume HP lebih pelan dari batas minimum bawaan.

- Atur redaman 0-40 dB lewat slider
- Atur lewat tombol di notifikasi: Lebih pelan, Lebih keras, Berhenti

## Build APK
Kode proyek ada di `VoluMin.zip`. Setiap ada commit ke `main`, GitHub Actions mengekstraknya dan membangun APK. Unduh hasilnya di tab **Actions** → build terbaru → **VoluMin-debug-apk**.
